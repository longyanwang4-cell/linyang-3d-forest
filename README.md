# 🌲 林样智记 V2.1 · 森林样地三维可视化与多期复测展示平台

本项目为**林样智记 V2.1** 纯前端三维可视化在线展示端（基于 Three.js WebGL 实时参数化建模与植物学纹理合成引擎）。

### 🚀 在线体验入口（点击直接打开）

- 🌲 **[进入三维森林主查看器 (`viewer.html`)](https://longyanwang4-cell.github.io/linyang-3d-forest/viewer.html)**
  - 支持 160 株实测样地秒级加载、单木高精度检尺卡片（`y=1.3m` 胸径与树高零误差校准）、多期分屏对比（支持 2 期 / 3 期 / N 期与自由拖拽调宽）、林调员 360° 自由漫游与升空飞行、单木实况自主标注（采伐年轮树桩 / 风倒木 / 枯立木）、自定义东西南北朝向与自由调查指令台。
- 🌏 **[进入 3D 地球与研究区导航中枢 (`map.html`)](https://longyanwang4-cell.github.io/linyang-3d-forest/map.html)**
  - 大兴安岭乌尔其汗—门德利研究区三维地球、大气瑞利散射光晕、等高线地形图切换与多样地缩略树位预览。
- 📋 **[进入样地数据管理与科研图件看板 (`manage.html`)](https://longyanwang4-cell.github.io/linyang-3d-forest/manage.html)**
  - 样地树位图 SVG、DBH-H 异速生长拟合曲线、径阶与树高分布图、Clark-Evans 空间格局分析、跨期复测质控核查与 CSV 导出。
